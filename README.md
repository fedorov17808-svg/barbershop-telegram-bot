# 💈 Barbershop Booking Bot

Telegram-бот для онлайн-записи в барбершоп: выбор услуги, мастера, даты и свободного времени в несколько кликов, плюс админ-панель для владельца.

## Возможности

- Пошаговая запись: услуга → мастер → дата → время → подтверждение
- Автоматический расчёт свободных слотов (занятые времена скрываются)
- Просмотр и отмена своих записей (`/my_bookings`, `/cancel`)
- Админ-команды для владельца барбершопа: список записей на сегодня и все предстоящие (`/today`, `/all_bookings`)
- Хранение записей в SQLite, никакой внешней инфраструктуры не требуется

## Стек

Python 3.10+, [aiogram 3](https://docs.aiogram.dev/), aiosqlite, python-dotenv.

## Запуск

```bash
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# в .env указать:
#   BOT_TOKEN  — токен бота от @BotFather
#   ADMIN_ID   — свой Telegram user id (для доступа к /today и /all_bookings)

python3 main.py
```

## Структура проекта

```
main.py                  # точка входа, запуск polling
bot/
  config.py              # настройки: услуги, мастера, часы работы
  database.py            # работа с SQLite (записи, слоты)
  services.py            # расчёт свободных слотов
  keyboards.py           # inline-клавиатуры
  handlers/
    client.py            # сценарий записи клиента (FSM)
    admin.py              # команды владельца барбершопа
```

## Настройка под свой барбершоп

Список услуг и мастеров редактируется в `bot/config.py` — цены, длительность услуг, часы работы и шаг слотов (по умолчанию 30 минут) настраиваются одной правкой без изменения остального кода.
